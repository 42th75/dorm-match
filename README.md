# 기숙사 룸메이트 배정

설문 응답으로 2인실 룸메이트를 자동 배정하는 웹 사이트.
서버 없이 정적 파일만으로 돌아가서 깃허브 페이지에 그대로 올라간다.

**처음이라면 [START.md](START.md) 를 순서대로 따라간다.**

---

## 무엇을 하는가

1. 구글 폼 응답(CSV)을 붙여넣으면 열을 자동으로 알아본다
2. 생활 습관에서 **비대칭 생활비용**을 만든다 — A가 B와 지내는 불편함과 그 반대가 다르다
3. **Irving 안정 룸메이트 알고리즘**으로 서로 방을 바꾸고 싶어하는 쌍이 없는 배정을 찾는다
4. 그런 배정이 존재하지 않으면 그 사실을 알리고, 불만 쌍이 가장 적은 배정을 준다
5. 세 가지 목표(안정 / 공평 / 총만족)로 각각 계산해 나란히 보여 준다
6. 결과 파일 하나만 커밋하면 학생들이 학번으로 자기 방을 확인한다

## 권한

| | 학생 | 관리자 |
|---|---|---|
| 학번으로 내 방 확인 | O | O |
| 전체 방 목록 | O | O |
| 배정 방식 설명 | O | O |
| 응답 불러오기 | X | O |
| 배정 실행·공개 | X | O |

비밀번호는 `js/config.js` 에 있다. 정적 사이트라 숨겨지지 않는다.
실수를 막는 잠금이지 보안 장치가 아니며, 실제 권한은 저장소에 push 할 수 있는 사람에게 있다.

## 개인정보

- **설문 원본과 기피 학번은 관리자 브라우저에만 저장된다.** 저장소에 올라가지 않는다
- 공개되는 `data/result.json` 에는 방 목록과 짧은 근거만 들어간다
- 기피는 한쪽만 적어도 양쪽에서 제외되고, 배정 근거 문구에도 나타나지 않는다

## 파일 구성

```
.
├── index.html          화면 구조
├── css/style.css       스타일
├── js/config.js        제목·비밀번호            ← 보통 여기만 고친다
├── js/matcher.js       배정 엔진 (화면과 무관한 순수 계산)
├── js/csv.js           구글 폼 CSV 읽기, 열 자동 인식
├── js/store.js         자료 보관과 권한
├── js/doc.js           배정 방식 설명 본문
├── js/ui.js            화면 그리기
└── data/result.json    공개되는 배정 결과       ← 배정할 때마다 갈아끼운다
```

`js/matcher.js` 는 DOM을 전혀 건드리지 않아서 Node에서 바로 불러 쓸 수 있다.
가중치를 바꾸거나 다른 알고리즘과 비교해 보려면 여기만 보면 된다.

```js
const M = require("./js/matcher.js");
const people = M.makeSample(80);
const r = M.solveAll(people, {});
console.log(r.results.stable.stats);
```

## 알고리즘 요약

**비대칭 생활비용** — 잠귀가 밝은 학생에게 두 시간 늦게 자는 룸메는 큰 부담이지만,
둔감한 학생에게는 같은 차이가 별일이 아니다. 그래서 민감도를 자기 쪽 값만 써서
시간 차이에 곱한다. 이 비대칭 때문에 두 사람의 선호 순위가 어긋나고, 그래서
안정 룸메이트 알고리즘이 필요해진다.

**Irving 알고리즘** — 제안 단계로 선호표를 줄이고, 회전 구조를 찾아 제거하기를
반복한다. 안정 배정이 있으면 반드시 찾고, 없으면 없다는 것을 증명한다.

**존재하지 않을 수 있다** — 남녀를 짝짓는 안정 결혼 문제와 달리 룸메이트 문제는
안정 배정이 아예 없을 수 있다. 80명 25회 시행에서 22회는 있었고 3회는 없었다.
없을 때는 차단 쌍 1~5개가 최선이었다.

**검증** — 4·6·8명 규모에서 가능한 모든 짝짓기를 전부 만들어 안정적인 것을 직접 골라낸 뒤
알고리즘 결과와 대조했다. 3,400회 전부 일치했고, 안정 배정이 없는 186건도 빠짐없이 잡아냈다.
